# DRAGON QUEST 3D — はじまりの島

非公式ファン制作の短編3DブラウザRPG。島・物語・モデル・効果音は本作向けに制作。

## 起動

このディレクトリの `index.html` をブラウザで開く。外部CDN・ビルド不要。
HTTPで開く場合はリポジトリ直下で `python3 -m http.server 8044 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8044/244-hajimari-no-shima/` へ。

## 操作と目的

- WASD / 矢印：移動。Q / R：カメラ回転。E / Space：調べる・会話を進める。
- スマートフォン：左スティックで移動、右ボタンで調べる。
- 西の村長で無料全回復・薬草補充。３つの祠で光を集め、北の竜を倒す。
- 戦闘はターン制。炎の予告の次のターンは「ぼうぎょ」が有効。
- 自動保存はブラウザのlocalStorageを利用。同じブラウザ・URLで「つづきから」。
- 敗北時は村へ復帰し、所持金半減。光のかけらと成長は維持。
- 音は初期OFF。右上で効果音をONにできる。

## 構成

`index.html` / `style.css` / `game.js` / `three.min.js`。
Three.jsは同リポジトリの既存MITライセンス版を同梱（著作権表記を保持）。

## 検証

`node 244-hajimari-no-shima/tests/smoke.cjs`（リポジトリ直下から。既存のplaywright-test依存と8044番サーバーを使用）。
戦闘・祠の検証はテスト用に位置を設定したうえで、実際の操作ハンドラーを実行する。全経路を歩いた実機プレイ検証とは異なる。
